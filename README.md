AI Engineer building RAG and agent systems on top of language models. My work
is about the distance between a model that answers well in a notebook and a
system people can actually depend on, which is where most of the engineering
turns out to live.

**Open to remote AI engineering roles, international or Brazil-based.**

##

### RAG & Agent Systems

| Project | What it solves | Highlight | Stack |
|---------|----------------|-----------|-------|
| [**sb100_agents**](https://github.com/LukeSantossz/sb100_agents) | Domain expertise locked in technical manuals and research literature is slow and expensive to query, and generic LLMs answer confidently without grounding | Self-hostable RAG API with a continuous 0.0 to 1.0 semantic-entropy hallucination score; JWT auth, rate limiting, 205 tests, ~83% coverage | Python · FastAPI · Qdrant · Ollama |
| **CollegeCompass** *(private, PM Accelerator)* | Prospective students navigate 1,800+ institutions with no grounded way to compare them against their own profile | Own retrieval and context assembly in a production RAG pipeline: hybrid search over pgvector, prompt assembly and citation verification feeding a Claude-based generation layer | Next.js · PostgreSQL/pgvector · Redis · Claude API |

### Machine Learning & Data

| Project | What it solves | Highlight | Stack |
|---------|----------------|-----------|-------|
| [**visiosoil-app**](https://github.com/LukeSantossz/visiosoil-app) | Soil texture assessment depends on lab analysis or trained specialists; neither works offline at scale | On-device classifier across 4 texture classes, 78.0% accuracy; 3rd of 1,000+ at FETEPS 2025, paper presented at ICPA/ConBAP 2026 | Flutter · Dart · TFLite · Riverpod |
| [**tweet-sentiment-analysis**](https://github.com/LukeSantossz/tweet-sentiment-analysis) | Generic sentiment classifiers fail on social-media language; slang and platform-specific syntax cause unreliable outputs | RoBERTa fine-tuning pipeline with a 0.71 macro F1 zero-shot baseline; Rust CLI ~42x faster preprocessing | Python · Rust · HuggingFace · Polars |
